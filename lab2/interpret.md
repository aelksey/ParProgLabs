## Интерпретация результатов вычислений

После успешного выполнения программы в консоль выводится сводная таблица **MPI Permutation Generation Benchmarks**. Все метрики сгруппированы по логическим блокам и интерпретируются следующим образом:

### 1. Параметры конфигурации задачи (Справка по исходным данным)
* **Elements in Set (N):** Размерность множества (количество элементов). Показывает число, которое программа успешно считала из аргументов командной строки или из конфигурационного файла (например, `input.txt`).
* **Total Permutations to Generate (N!):** Общее количество перестановок, которое необходимо найти и записать. Вычисляется автоматически как \(N!\) (факториал числа \(N\)). Позволяет оценить масштаб вычислительной сложности (например, при \(N=9\) генерируется \(362\,880\) вариантов, а при \(N=10\) объем работы вырастает в 10 раз — до \(3\,628\,800\)).
* **MPI Processes (Degree of Parallelism):** Степень распараллеливания. Это количество независимых MPI-процессов (ядер/потоков), выделенных операционной системой под данную задачу при запуске через `mpiexec -n <P>`. Именно между этим количеством процессов поровну делится общее пространство перестановок.

### 2. Временные метрики (Сравнение производительности)
* **Sequential Execution Time:** Время выполнения последовательного алгоритма (в секундах) на мастер-процессе (`rank == 0`). Этот замер используется в качестве эталона базовой производительности системы.
* **Parallel Execution Time (Max Process):** Время выполнения параллельного алгоритма (в секундах). Поскольку процессы работают асинхронно, в таблице отображается время работы **самого медленного (последнего завершившегося)** процесса, полученное с помощью функции `MPI_Reduce` с операцией `MPI_MAX`. Это честное время, за которое задача была решена параллельно.

### 3. Критерии эффективности параллелизма
* **Achieved Speedup Factor (Коэффициент ускорения):** Вычисляется по формуле \(S = T_{seq} / T_{par}\). 
  * Значение показывает, **во сколько раз** параллельная программа отработала быстрее последовательной. 
  * *Пример:* Значение `3.81x` на 4 процессах говорит о практически линейном ускорении.
* **Parallel Efficiency Rate (Эффективность использования ресурсов):** Вычисляется по формуле \(E = (S / P) \times 100\%\), где \(P\) — количество процессов.
  * Показывает, насколько эффективно каждый выделенный процессор был загружен полезной работой, а не простаивал в ожидании. 
  * *Пример:* Значение `95.25%` означает, что накладные расходы на инициализацию MPI и запись файлов заняли всего около 4.75% времени, что является отличным результатом.

### 4. Верификация корректности
* **Software Verification Status:** Статус программной проверки результатов на совпадение. 
  * `SUCCESS (Identical)`: Означает, что встроенный валидатор пошагово сравнил файл последовательного расчета `seq_output.txt` со всеми файлами параллельных процессов `par_output_rank_*.txt` и подтвердил их стопроцентную идентичность. Это доказывает, что при распараллеливании не было потеряно или продублировано ни одной перестановки.
  * `ERROR (Mismatch!)`: Сигнализирует о логической ошибке в коде (неверно рассчитаны диапазоны или стартовые индексы процессов).
