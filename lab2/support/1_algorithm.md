## Часть 1. Базовый алгоритм — Метод Нараяны (Переход к следующей перестановке)
В последовательном коде и внутри циклов параллельных процессов мы используем алгоритм Нараяны. Это классический нерекурсивный алгоритм, который находит следующую в лексикографическом (алфавитном) порядке перестановку.
Алгоритм состоит из 4 обязательных шагов (покажите это на примере массива [1, 4, 3, 2]):

   1. Поиск первого спада справа (i): Мы идем с конца массива налево и ищем первый элемент, который меньше своего правого соседа ($A[i] < A[i+1]$).
   * Пример: Идем с конца: 2 -> 3 (растет), 3 -> 4 (растет), 4 -> 1 (упало!). Наш элемент — 1 (индекс $i$).
   2. Поиск элемента для замены (j): Мы снова идем с конца массива налево и ищем первый элемент, который строго больше найденного на шаге 1 ($A[j] > A[i]$).
   * Пример: Ищем элемент больше 1 с конца: 2 больше 1? Да! Наш элемент — 2 (индекс $j$).
   3. Обмен (Swap): Меняем местами элементы с индексами $i$ и $j$.
   * Пример: Меняем 1 и 2. Массив становится: [2, 4, 3, 1].
   4. Переворот хвоста (Reverse): Разворачиваем (инвертируем) всю часть массива, которая находится справа от индекса $i$ (то есть от $i+1$ до конца).
   * Пример: Хвост после бывшей единицы — это [4, 3, 1]. Переворачиваем его, получаем [1, 3, 4].
      * Итог: Из [1, 4, 3, 2] мы получили следующую перестановку: [2, 1, 3, 4].
   
Если на шаге 1 мы дошли до начала массива и не нашли спада (например, [4, 3, 2, 1]), значит, это была самая последняя перестановка, и алгоритм завершает работу.

## Часть 2. Главная «фишка» параллелизма — Поиск по порядковому номеру (Индексу)
Преподаватель обязательно спросит: «Как процесс №3 понимает, с какой именно перестановки ему начинать работу, не вычисляя предыдущие?»
Для этого вы отвечаете: «Я использую факториальную систему счисления». Она позволяет за линейное время $O(N^2)$ найти перестановку по её абсолютному порядковому номеру (от 0 до N!-1).
Как это работает на пальцах:
Пусть $N=4$ ($4! = 24$ перестановок), у нас есть доступные числа [1, 2, 3, 4]. Процессу нужно найти перестановку с индексом 14.

   1. Мы знаем, что все 24 перестановки разбиты на 4 группы по первой цифре. Размер одной группы: $(N-1)! = 3! = 6$ перестановок.
   2. Делим наш индекс на размер группы: $14 / 6 = \mathbf{2}$ (остаток $2$).
   3. Результат деления (2) указывает на индекс элемента в нашем списке доступных чисел [1, 2, 3, 4]. Под индексом 2 (начиная с 0) идет число 3.
   * Первая цифра найдена: 3. Удаляем её из списка доступных. Осталось: [1, 2, 4].
   4. Теперь ищем вторую цифру. Наш новый индекс — это остаток, то есть $2$. Новый размер группы для оставшихся 3 элементов: $(N-2)! = 2! = 2$.
   5. Делим: $2 / 2 = \mathbf{1}$ (остаток $0$).
   6. Под индексом 1 в списке [1, 2, 4] идет число 2.
   * Вторая цифра найдена: 2. Удаляем. Осталось: [1, 4].
   7. Повторяем для третьей цифры с остатком $0$. Размер группы: $1! = 1$. Делим: $0 / 1 = \mathbf{0}$ (остаток $0$). Под индексом 0 идет число 1.
   * Третья цифра найдена: 1. Удаляем. Осталось: [4].
   8. Последнее оставшееся число — 4.

Итог: 14-я по счету перестановка для $N=4$ — это [3, 2, 1, 4]. Процесс мгновенно вычисляет этот массив и начинает от него работать дальше с помощью алгоритма Нараяны.
